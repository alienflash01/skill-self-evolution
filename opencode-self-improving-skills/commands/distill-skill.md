---
description: 把刚完成的工作里可复用的技法蒸馏成学习技能（手动触发）
agent: build
---

回顾刚完成的工作，若有可复用的技法、模式或解法，把它蒸馏成学习技能。

这是自改进循环的**手动触发**（与 session.idle 自动提醒做同一件事，在你想要时手动运行）。

**委派给 skill-distiller 子代理：** 用 Task 工具，参数 `subagent_type="skill-distiller"`，简要说明这次会话做了什么、什么是非显然的（解决了什么问题、发现了什么 API/库的行为）。子代理会：

1. 扫描 `~/.config/opencode/skills/**/SKILL.md` 看有没有相关的现有技能，
2. 有就 **patch**，没有（且 class 级可复用）才**新建技能**，
3. 若是一次性/环境相关/不可复用的知识，就什么都不写，并用一行说明原因。

$ARGUMENTS 若有，把其中的指引（例如聚焦某个技法、或更新某个现有技能）一起转达给子代理。

> 蒸馏只有在存在「可复用技法」时才有意义。若只是单纯的功能实现、重构或一次性修复，子代理自行判断为「无需创建」并结束是正常的。
